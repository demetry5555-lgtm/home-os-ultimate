# HOME OS ULTIMATE

Family operating system: finances, tasks, requests, calendar, apartment finishing, chat, documents — English-first with an Arabic toggle, Black & Gold.

- Web app: Vite + React 18 + TypeScript + Tailwind, Supabase (auth, Postgres RLS, storage).
- Offline demo mode: `VITE_DEMO_MODE=1` mirrors the SQL semantics in localStorage.
- Database setup: idempotent SQL parts, see `supabase/parts/` and the hosted setup page.
- Deploy + APK on your phone: see **DEPLOY.md**.
